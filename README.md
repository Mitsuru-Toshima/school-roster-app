# （日専校）学籍マネージャー - School Roster App

日専校向け統合学籍管理・座席表・寮生点呼簿・各種日誌Webアプリケーション

## 主な機能
1. **座席表（出席簿用）**:
   - 教卓側から見て右側から縦に出席番号順（出席簿原本完全準拠）
   - 写真下枠極小表示（写真の1/10以下、クラス名なし、出席番号＋氏名のみ）
   - 空席自動非表示（枠線・文字なし透明化）
   - A4縦1枚自動収容（印刷時に2枚目へのはみ出し防止）
   - 特別教室プリセット:
       - 特別教室（講座）: 6列×11行 (66席)
       - 特別教室（グループ学習）: 3×3配列 各島6名対面着席 (54席)
2. **生徒名簿（出席簿）**:
   - ふりがな: Q列、出身中学: V列、帰省先住所: AG列 (番地省略)、委員会: CG列から完全引用
   - 1〜5番号、備考削除
   - 部活動名フルネーム表示
3. **寮生点呼簿（週間記録）**:
   - CJ列で寮生判定、CW列から部屋番号取得
   - 2-301（2寮3階1号室）の階層ソート＆フロア単位A4印刷
   - 週間日付スクロール（前週/次週）
   - 不在者リアルタイムダッシュボード＆集計CSV出力
4. **ロッカー用ネームプレート**:
   - 名前のみ枠いっぱいに特大表示
   - 学年絞り込み（1年/2年/3年/全学年）
   - 正確なミリ寸法印刷
5. **証明写真印刷**:
   - 専用の証明写真登録ボタン（一般写真とは別管理）
   - 名前ラベルを切り取り枠外に配置し、カット時に正確なミリ寸法を維持
6. **ネームプレート（寮 4×3cm）**:
   - 縦40mm × 横30mm、写真面積8割以上（80.6%）
   - 写真脇に縦書き氏名、写真下に部屋番号と部活名を横並び配置
7. **各種日誌（日直・宿直・保健室）**:
   - 過去の日誌閲覧・再編集機能（履歴セレクタ）
   - 天候・学校のプルダウン選択
   - 巡回時間①〜⑤の5回記入
   - 生徒選択で部屋・部活・クラス・住所自動展開
   - 期間まとめ（週間／月間／4半期／半期／年間）印刷＆CSV出力
8. **スマホ・タブレット イマーシブ対応**:
   - 全画面表示（イマーシブモード）
   - タップによる座席スワップ
   - パネル折りたたみ・ズーム倍率調整

## 起動方法
```bash
npm install
npm run dev
```
ブラウザで `http://localhost:5173/` を開いてご利用ください。
